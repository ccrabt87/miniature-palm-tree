# Changelog

All notable changes to the Zeros to Heroes Tryptych Dice Roller will be documented here.

## [1.0.0] - 2026-01-16

### Added
- Initial release with monetization features
- Tryptych dice rolling system (3 axes: Stat, Context, Symbolic)
- Live probability calculator
- Roll history tracking (50 rolls free, unlimited premium)
- Character preset system with save/load/delete
- Export to JSON and CSV
- Itch.io API integration for automatic premium unlock
- Premium features:
  - Advanced analytics dashboard
  - Unlimited roll history
  - Markdown export
  - Import/export preset collections
- Beautiful gradient UI with animations
- Mobile-responsive design
- LocalStorage persistence
- Keyboard shortcuts (Space/Enter to roll)

### Free Features
- Full tryptych rolling functionality
- 50-roll history limit
- Save/load character presets
- JSON and CSV export
- Real-time probability calculations
- Beautiful animated interface

### Premium Features
- Advanced analytics with statistics
- Unlimited roll history
- Export rolls to Markdown format
- Import/export preset collections
- Future: Custom themes
